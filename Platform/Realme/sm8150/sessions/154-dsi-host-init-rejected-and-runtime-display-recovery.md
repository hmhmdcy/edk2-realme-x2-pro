# 154：停止继承DSI CTRL不足以修复首次白屏

153在运行时标准DPMS后停止欠载，实体电源键唤醒仍曾花屏。原厂面板明确要求首帧完成后更新背光；一次runtime对照用DPU TX完成事件恢复亮度，用户未看见自动对照，但随后手动尝试正常。尚未实现永久背光策略。

154独立验证另一处DSI初始化缺陷：先关闭继承CTRL，再改写时序和复位。实际函数及完整构建通过，只更新logdump；真实首次启动CTL成功，但DSI欠载持续，用户看到白屏和局部闪烁花屏。标准关屏、开屏恢复后，用户确认桌面/锁屏；不能验收154为修复成功。

启动原始寄存器和trace已保存。完整KMS第一快照实际在自动关屏后，active=0，与恢复后active=1不具故障对照资格；155准备保持同一154镜像，重新启动获取有效亮屏快照。当前分区、模块、NV和Mesa修复验证通过，详细失败和恢复证据见[154记录](../reference/kernel154/README.md)。
