# 156：首帧后亮屏与桌面提前启动

用户反馈同一 #154 重启后电源键开屏仍偶尔花屏，开机经过命令行、数秒白屏花屏、命令行等待，最后进入锁屏。155 正常启动零 DSI 错误并未覆盖这些实体问题。

156 已刷入并核验实际 #156、新 boot 和 logdump 读回。实现 SOFEF03F 首帧背光门控，实际 12 次亮屏全部在 PP TX done 与成功 TX wait 后放行，24 次电源转换零新增错误。greetd 设置 rc_before=samurai-radio，保持无线 45 秒观察和校准流程，Phosh 由 79.67 秒提前到 20.62 秒。

首次 boot 仍有 78 条 DSI 错误，全启动显示验收失败；用户外出，物理画面待确认。当前继续修复接管顺序，157 源码候选先停止固件 DSI 控制器，再重配 PHY/PLL，仅在首次接管执行。15 项真实函数与失败回退测试通过，完整构建进行中；手机仍为 #156。

详情见 [156 证据](../reference/kernel156/README.md) 与 [155 对照](../reference/kernel155/README.md)。既有 GPU147/149 修复和当前四类工作边界保持。
