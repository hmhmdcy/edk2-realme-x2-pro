## 性能限制与续作

同一缓存FULL交替新旧各16次，相对445旧中位1.039—1.279ms，新0.655—0.835ms，约1.53—1.59倍；这是缓存CPU样本，不包括DMA／映射。实际720p焦点中位3.308ms，1080p为12.892ms；采样最大38.854／40.699ms，仍有超过33ms的帧。[时延](latency-validation.json)、[有界比较](comparison-validation.json)。

去掉前8帧后，720p／1080p分别约29.266／27.125fps，稳态跳3／12个SOF。与445跨恢复启动的场景、温度、调度未受控，不能归因于工作区改动，也不能认证普遍提速、持续录像或关闭旧441积压根因。工作区分配已移出稳态采样，下一步定向区分线程CPU时间、缺页／访存与调度等待，再决定底层修复；不要继续把缓存CPU提速当作录像验收。

协议6其余三模组的隔离自动路径、RAW／双流和主摄实际AF覆盖已补齐。本轮未补其它模组镜头驱动／实际AF、普通消费者的新全矩阵或绝对画质。其它尺寸、持续录像、legacy／manual／v2／HDR、光学、第五2MP和多摄几何／同步仍按[完整范围](../kernel363/REMAINING-CAMERA-SCOPE.md)推进，优先匹配原厂数据。
