# r2 为待实机验证的 PM 候选

第二轮实测确认安装脚本仅为advisory，返回失败仍可能提交文件/数据库。唯一推荐入口是在APK前外部完成校验的显式事务，详见STAGED-ROLLBACK.md；隔离root闭环已验证，手机事务未执行。已签名r2不修改。

`0.1.0-r2` 使用transport的独立 k363 hci_uart，140136字节，SHA-256 `fe14136068584d212625a7c2bfb20b72e082539daa10dfcecd877e43531fc32d`。同包的btbcm、btqca及185功率脉冲/H4行为保持。r1独立封存，不作为本候选的安装前置；r2钩子要求现有文件仍是r0基线。

本候选包含r1的SLEEP短写和负等待返回检查，另在已quiesced的失败路径锁内按实际TX状态恢复timer，TX_WAKING补充必要clock vote，TX_ASLEEP且有排队数据时重启WAKE。33例返回值和19例失败恢复模型通过，构建为精确k363配置与符号、W1/Werror零诊断。模型与构建不等于设备PM验收，主线应先审查具体补丁和适用状态。

安装/升级钩子只做边界检查：实际机型/release正确，现有三个模块逐字匹配r0，`bluetoothd`已停止且hci_uart未加载。钩子不停止服务、不卸模块、不运行depmod、不重启。owner、实际canonical path和服务停用顺序由当前设备窗口核对；本包未安装。

185来源、363来源和r2固定补丁/模型/构建快照均随包保存。需要在受控蓝牙窗口部署后验证故障恢复、扫描、连接和相关PM路径；不能将r0的历史扫描或本轮ASan模型扩大为r2完整蓝牙功能通过。
