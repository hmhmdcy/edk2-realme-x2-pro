# 上游IMX471时序交叉核对

2026-10-16补查，发生在本机四组120帧测量及e49模块回归之后。没有运行网上脚本或用其它机型的供电配置替换本机配置。

[9月2日修订](https://lists.openwall.net/linux-kernel/2026/09/02/2690)作者在ThinkPad实机也读到旧模式行长5120，并报告387.2MHz阵列速率；其原模式没有写行长。这与本机活动寄存器及约17.296ms帧间隔一致。两者是不同硬件的测量，不能据此声称笔记本的镜头或校准适用于手机。

[9月8日讨论](https://lkml.iu.edu/2609.1/00687.html)区分OP串行输出与VT阵列时钟；[10月7日v3补丁](https://lists.openwall.net/linux-kernel/2026/10/07/199)按外部时钟、VT倍频与三个分频值计算，并乘四路。其公式与本轮活动寄存器推导一致。本机另外两种原厂模式的倍频/预分频不同，分别得到326.4MHz与约578.133MHz，并由各120帧时间戳独立校验。

本机显式将旧模式行长写成已实测的5120，防止从其它模式返回时继承不同的行长；保持所有PLL表和链路频率不变。上游讨论还涉及可变HBLANK与其它寄存器改动，本轮没有未经本机测量直接合入这些部分。此处确认的是时序关系，标准几何/CFA、实际画质和RGB实时吞吐仍需继续验收。
