# 414：原厂 TMC11 三层触发插值与动态数值链

完成实际 HAL 的 DRC→HDR→AEC 选区及 AEC→HDR→DRC 回填插值；这是用户空间数值适配。内核仍为406，SoC、板级DT、主线驱动、传感器及默认运行配置没有改动。本轮手机访问及新增硬件帧均为0，最后实机证据仍是[406](../kernel406/README.md)。完整多摄／骁龙ISP目标继续。

## 原厂 ABI 与实现

[tree-model.py](tree-model.py)执行原厂模块前缀`0x383cdc..0x384048`，包括实际搜索器`0x4ac150/0x4ac498/0x4ac908`及插值回调`0x4ab450`。除`memset`外未替换数学或搜索函数。区域基址为SP+64，X23必须指向该处。原模块根136B、DRC节点24B、HDR节点40B、AEC叶192B；后者为16B触发区间及176B/44float区域。

根的AEC/HDR控制位为68/72，core计数及指针为120/128。模块DRC在72、realGain/lux在80/84。HDR控制0读取模块88、控制1读取92；本机控制2将触发值置零，再按第三组区间搜索。公开新版头文件的第三个HDR浮点输入不能直接套用到本机。88/92上游语义身份仍未定位，公共接口使用实际偏移名，不冒充已验证的曝光时间／灵敏度字段。

[libipa/tmc11_tree.cpp](libipa/tmc11_tree.cpp)使用显式输入树，保持原序first-match；支持区间重叠、区内复制、区间间隙插值和两端选区。ratio先用double计算再转float。44字段插值保持整数／小数拆分、1e6缩放及独立舍入，禁止融合改变结果。按实际搜索器20区间容量检查每级节点数；非法或非有限输入原子拒绝，不改输入树或输出。该接口只计算数值，不选原厂模式根、不启用关闭根、不修改运行版本。

## 验证

[tree-validation.json](tree-validation.json)：68个原厂根全部覆盖，共2,524原厂触发用例、322多级合成用例、15非法输入；主机ASan/UBSan和ARM64 SDK/QEMU各比较514,980B，零差。原厂指令执行2,847,529条，仅`memset`提供器。包括各级20区间搜索、三层同时双子节点、边界相邻float、负值／整数小数舍入、重叠区间及HDR2改变两个输入仍触发零的对照。

68原厂根的控制均为[0,0]，每根只有一段DRC、一段HDR，AEC共198叶。强制gain控制及HDR1/2、多DRC/HDR树是数值夹具，不能称为原厂运行模式。关闭根也只做数值核对；qtech GW1仍是未绑定物理模式的供应商文件，不能据此增加第五颗摄像头。

[dynamic-chain-validation.json](dynamic-chain-validation.json)从68根各选两种触发状态，共136项、其中51项实际间隙插值，将本次便携插值的实际输出接入413生成、412采样、409 ADRC及维护内核typed LUT编码。两架构生成全状态各1,127,712B零差，131份有效LUT共67,072B与native编码一致；5项有限首点增益低于1024，按409契约原子拒绝，没有强行夹到unity。原厂生成／采样／ADRC分别执行33,599,012／1,508,536／1,254,515条指令。各阶段在独立进程串接，未接入产品请求生命周期。原始插值金样复用本次2846用例的已核对输出，生成／采样／ADRC仍执行原厂指令；logf/expf/powf采用host libm，最终packer采用已核对源码程序，不能称整个原HAL已运行。

统计为合成均匀／黑峰，Gamma和原厂私表取已留存原件，原始树、表、汇编、输入及输出仅存于`/mnt/e/edk2-samurai-out/kernel414`及前序私有目录。公共目录不含原厂校准数组。复用[412树提取及模式选择证据](../kernel412/README.md)、[413曲线生成证据](../kernel413/README.md)，没有重新下载资料或重复旧组件全回归。
