## 实际像素结果

一次事务 `k400-chain-r1`，worker12945、collector13040。16帧均走native direct路径，starts／stops16、失败／取消0，无驱动CPU图像处理。[独立主机像素检查](pixels-validation.json)重算全部客户端CRC，验证输入生成器及下列结果；每帧460800字节。

|固定模式|实测|
|---|---|
|0：旁路|全部307200个Y字节等于输入|
|1：CST＋CV|灰阶块亮度与输入一致；颜色块包含原厂CV及转换的作用|
|2：转换对＋单位CCM|全部460800字节等于模式1|
|3：转换对＋零CCM|全部Y为0，全部UV为128；与397转换关闭时UV也归零的行为不同|
|4：转换对＋半幅CCM|Y／UV均围绕模式3的编码黑色减半；`2×半幅−单位−黑色`全帧仅−1、0、1|
|5：转换对＋R／B交换|相对单位模式358968字节改变|
|6：转换对＋RGB偏移(−64,+32,+96)|相对单位模式425675字节改变|
|7：转换对＋相反偏移|相对单位模式360759字节改变|

八种模式在NV12／NV21通道归一化后，全部输出字节相同。中间色块的模式6亮度增加1，模式7反向变化，二者与单位模式的对称和误差不超过1。

这支持所测固定配置中已建立CST→CCM→CV的RGB处理域，并证明非对角及有符号偏移路径有效。不能把这个有限范围扩成全部矩阵、尺寸、舍入、饱和或正常照明色彩校准完成。转换对本身也不要求对所有颜色逐字节等于旁路，所选原厂CV包含不对称调校参数。

[亮度推断](luma-inference.json)把19块用于拟合、29块留作观察：首个最低训练误差模型在留出集最大误差1字节。但有三个模型训练分数相同，映射／舍入仍有歧义；该分析明确为推断，不作为独立硬件公式或偏移量纲证明。完整通道方程尚未证明，自动应用原厂矩阵仍未就绪。
