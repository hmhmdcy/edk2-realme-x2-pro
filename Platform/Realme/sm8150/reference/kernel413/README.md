## 发现并保留的版本差异

本机有限暗部膝点商不会被第二锚点裁剪：该编译路径的下界就是商本身，后续选择保留商；固定辅助源码按另一种Clamp语义会得到min结果。首轮[生成失败](generation-r1-validation.json)在26项中产生251字节差异，两个架构相同，涉及暗部膝点及其系数。已按目标修正；原始输出私存，修正后的主机／ARM只复用未改动的目标记录，没有重复执行无关区段。

没有统计指针与“指针存在但全0统计”是两条不同路径。前者的原HAL对比度初始化调用memset的**字节1**，并不是浮点unity；当前实现准确保留，不能将它误当作正常直方图结果或替换成浮点1。纯直方图混合在缺失／全0统计下可生成非有限系数，公共接口保留调用方输出并拒绝继续下发。

两份模型夹具失败也保留：[第一次](model-r1-validation.json)把X23设为SP，实际应为区域基址SP+64；[第二次](model-r2-validation.json)漏设原前序代码保存的Gamma指针X24=模块+112，导致1023个对比度节点读取错误内存并退到1。修正实际ABI，未改目标指令或公共数学来迎合错误夹具。
