# 407：移植 LTM 曲线生成、曝光衰减及非零 scale／LCE 量化

在406固定LTM硬件验证之后，新增可移植用户空间数学：[ltm_curves.h](libipa/ltm_curves.h)、[ltm_curves.cpp](libipa/ltm_curves.cpp)。支持原厂手动曲线的暗部／亮部区域处理、自动曲线、LTM／LCE强度、曝光变化衰减，以及64段LTM scale和两组16段LCE量化。**完整LTM／ADRC、原厂额外时域平滑、动态触发树和产品接入仍未完成；完整多摄／ISP目标保持active。** 本轮没有访问手机或安装新模块，最后实机状态仍是[406正式驱动恢复与四摄48帧](../kernel406/current-state-validation.json)。

## 来源和复用

复用351从五份原厂BIN恢复的149根／2135区域和403保留的固定版本LTM源码。没有重复下载固件、读取个体校准或把原厂系数写入公共代码。[来源](primary-sources.json)。源码片段仅在私有参考程序中编译；公共模块为独立类型和实现，输入是已插值区域值，输出仍需后续完整处理链组合。

本轮补查现有方案：[CAMSS pipeline RFC](https://lists.libcamera.org/pipermail/libcamera-devel/2026-April/058088.html)提供可扩展硬件ISP的接口，[后续OPE RFC](https://patchwork.libcamera.org/patch/26514/)针对另一ISP后端。这些可供后续用户空间接入参考，没有作为本机SM8150／IPE LTM数值等价或已适配的证据。

浮点曲线计算放在用户空间，内核继续接收405已检查的类型化量化请求。本轮没有修改406维护内核、板级DT、传感器、主线框架、产品IPA或默认参数；保持底层几何和DMA／请求所有权修正。

## 数值及本机原HAL证据

[检查](curves-validation.json)覆盖五份原厂表全部2135区域，每区域三个曝光变化条件，共6405项；另加48项手动曲线／曝光边界和96项自动曲线，总6549项。包括无零点、零平台、正负曲线、反向曝光变化、衰减阈值相等／反序、自动曲线输入限幅和有符号差值越界。

主机ASan／UBSan与现有AArch64 SDK／QEMU构建均通过，源参考的96个量化表项逐字节零差。81项非法输入及14项额外非法编码输入保持输出不变，输入也不被曲线生成器改写。LTM的int16转换范围在类型化接口明确检查；不依赖溢出转换。LCE先按原厂限幅，负差值保留其实际掩码规则。

[本机HAL模型](curve-model.py)执行两段原指令：`0x35ec64…0x360560`的自动／手动区域和强度处理，以及`0x360ac8…0x360c3c`的曝光衰减，累计6587698条指令，覆盖相同6549项。中间OEM时域／自适应区段明确跳过，未声称运行整个Execute。[浮点对照](float-comparison-validation.json)证明主机、AArch64及该原HAL片段的99个浮点输出逐字节一致。

自动分支的12480次外部powf调用由主机libm提供，没有执行原目标Bionic powf。固定源码参考调用双精度pow，与本机片段／可移植实现相比，96项自动用例中总计4个浮点字节不同，最大绝对差0.00006103515625；量化后无差。原厂／手动用例连浮点字节也无差。没有把这一结果扩大为所有浮点库和任意输入均等价。

原HAL生成的浮点结果按已核对的源打包规则再量化后，与源参考表零差；本轮没有执行原HAL最终LUT打包区段。该边界在报告中保留，不把浮点片段加参考打包写成整个HAL最终输出已执行。

## 打包差异修正与内核连接

[首轮失败](curves-r1-validation.json)保留：通用实现错误地让LCE也强制负差值符号位，随机自动用例有208个表字节不匹配；原厂和手动边界用例当时未差。原厂LTM scale会显式强制负差值符号位，而LCE仅作掩码，超出有符号12bit差值范围时两者不能共用同一规则。修正后两架构全部通过。首轮主机结果及差异明细私存；缺少交叉g++时复用现有SDK，没有因此安装另一套工具链。

[内核LUT连接检查](kernel-luts-validation.json)重新编译与维护树相同的颜色编码器，把全部6549项结果解成类型化有符号base／delta并传入2800字节请求。最终8944字节IQ页中的scale／LCE共2514816字节，与源参考零差，其中3536项包含非零表；请求输入和输出尾部保持。该检查实际运行现有原生内核编码函数，未提交硬件，也未将其余零填充表／控制位称作完整原厂配置。
