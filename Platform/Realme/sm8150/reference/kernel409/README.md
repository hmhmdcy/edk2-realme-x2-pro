## 原厂证据与输入域

本机原HAL `0x362774…0x3642d4` 完成已采样增益到65点scale／curve的转换；`0x3642d4…0x364598` 紧接着混合原LTM曲线。[实际执行模型](adrc-model.py)覆盖两段原指令，累计27076690条指令，唯一provider是2783次内存复制；这两个区段无需替代Bionic数学函数。

接口显式接收65点12bit等效输入、Q10已采样增益及65点IFE forward Gamma，首增益至少unity。支持全部有限非负采样增益，含float最大值边界；没有以64倍增益作无依据的上限。内部按原厂顺序裁剪索引、构造非递增scale、作三轮顺序平滑，再构造带平坦区和四轮顺序平滑的curve。循环必须使用已更新的左邻值。

原厂插值先拆整数／小数，小数放大1000000并用双精度运算，再分别舍入和合并。公共实现保留这些舍入边界，`-ffp-contract=fast` 下仍与目标一致，未改为普通float lerp。混合量大于0时curve比例为3，否则为1；curve按最近值取整，scale在max运算后截断为int16，两者不能统一round。
